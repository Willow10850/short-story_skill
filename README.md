# 爽文风格训练舱 · README

> 一个用"内核 + 风格层 + 题材卡"三层拼装方式，稳定产出女频短篇爽文的写作训练项目。

---

## 一、这个项目是干什么的

把"写爽文"从"凭感觉"变成"按配方"。

核心思路只有一句话：**把不随题材变化的东西锁死（内核），把随作者变化的东西拆开（风格层），把随热点变化的东西外挂（题材卡/热梗卡）。** 换题材时只换两行卡片，其余全部复用。

产出目标：8,000–12,000 汉字的单篇女频短篇爽文，第一人称冷叙述，卡点在全文 40%–50%。

---

## 二、文件清单与各自职责

| 文件 | 层级 | 职责 | 变动频率 |
|------|------|------|----------|
| `内核层_v1.md` | 内核 | 题材无关的节奏、结构、文体、禁忌、验收规则 | 极低（季度级） |
| `风格_作者名.md` | 风格层 | 单个作者的句式、对白、视角、情绪、修辞习惯 | 低（有新范文时） |
| `项目启动包.md` | 操作手册 | 建项目、开对话、跑验收、拼装模板 | 中 |
| `风格_xxx.txt` | 素材 | 范文原文，用于提炼风格层 | 只增不改 |
| 本文件 `README.md` | 索引 | 项目总览与使用路径 | 低 |

**内核层不绑定题材**：世界观、身份落差、觉醒方式、隐藏实力、女配罪行、处刑舞台等，全部由外部题材卡注入，内核只提供槽位。

**风格层不绑定剧情**：只描述"怎么写"，不描述"写什么"。两位作者的风格层写同一个题材，输出必须能被人一眼区分。

---

## 三、四层拼装：每次写稿的固定动作

```
【内核】   粘贴 内核层_v1.md 全文
【风格层】 粘贴选定作者的 风格_作者名.md 全文
【题材卡】 题材｜核心梗｜主角人设｜爽点类型｜目标平台｜字数｜禁忌点
【热梗卡】 梗｜热梗用法｜卡点类型｜时效状态
【本次要求】本篇特殊要求，没有就写"按标准流程"
```

题材卡和热梗卡从飞书「热梗选题库」复制对应行填入。**换题材 = 换两行，其余不动。**

拼装顺序不可颠倒：内核定骨架 → 风格层定血肉 → 题材卡定皮肤 → 热梗卡定时效。

## 四、九节骨架速查（内核层摘要）

| 节 | 占比 | 一句话功能 |
|----|------|-----------|
| 引子 | 2–3% | 三行立反常识设定 + 觉醒知死局 + 反常抉择 |
| 1 决裂宣言 | 10% | 第一次拒绝，旧阵营 N 人各一句声口台词 |
| 2 三连斩断 | 15% | 斩关系、斩身份、斩血缘，全虐但每次回敬冷台词 |
| 3 低谷+小爽 | 9% | 谷底第一次亮实力，"摘下道具"触发 |
| 4 对峙→卡点 | 8% | 误解拉满 + 铁证落地 + 定格切镜 |
| 5 卡点释放 | 11% | 反应镜头 + 新干扰 + 再断一层 + 新阵营护主 |
| 6 真相揭晓 | 9% | 最懂行的旧人先崩溃，暗线罪行曝光 |
| 7 火葬场初段 | 9% | 道歉/下跪/痛哭各一特写，全部被拒 |
| 8 公开处刑 | 12% | 女配主场变主角封神台阶 |
| 9 封神收束 | 13% | 官方定级 + 火葬场完成式 + 两句点题 |

卡点铁律：**左边是憋屈峰值，右边是打脸起点，卡点是引爆器。** 写完实测占比，不达标调前后篇幅，不动卡点事件本身。

## 五、使用路径

**首次搭建（一次性）**

1. 建项目，粘贴 `项目启动包.md` 第一节的项目指令
2. 上传 `内核层_v1.md` + 范文（每位作者 1–2 篇，文件名标作者）
3. 开「内核校验」对话，验证内核有无遗漏

**每位新作者入库**

1. 开独立对话「风格-作者名」，按五维度拆解（句式节奏/对白习惯/叙述视角/情绪写法/高频修辞）
2. 过三道验收：拼贴检查、辨识度测试、稳定性测试
3. 存成 `风格_作者名.md` 回传项目文件

**每次写稿**

1. 按第三节模板拼装四层
2. 跑开篇 500 字，对照固定测试题材 T1/T2 与上次输出比对
3. 单篇修改用"只改第 X 节，只输出修改后的段落"，禁止整篇重写
4. 改稿经验记入飞书「改稿记录」，每周归纳回内核层或风格层

---

## 六、三道验收（任何风格层产出都必须过）

1. **拼贴检查**：挑 3 句去搜索引擎搜，搜不到范文原句才算过
2. **辨识度测试**：两位作者风格层各写同题开篇 300 字，遮住标签能分清才算过
3. **稳定性测试**：同一风格层、同一题材连跑 2 次，质量不忽高忽低才算过

---

## 七、两个固定回归测试题材

- **T1（现言）**：我是被调包的假千金，真千金回家当天，全家等着看我哭闹，我主动签了断亲协议。
  测试点：断亲戏、称谓仪表盘、合唱团
- **T2（古言）**：重生回到替嫁花轿落地前一刻，前世我在侯府被榨干至死，这次我掀开盖头自己走了出来。
  测试点：重生开局、二次悬念、冷叙述

每次改完内核或风格层都跑这两个，同样的输入质量不滑坡，才算改对了。
