# short-story_skill · 爽文风格训练舱

> 一个自我进化的女频短篇爽文写作配方：**喂例文拆配方 → 写稿 → 投稿 → 把编辑反馈炼回配方**。
> 当前核心产物：`xiaochengxu-houhvi-shuangwen`（小程序体/盐选体后悔流短篇 skill，**v5**）。

---

## 一、这个仓库是干什么的

把"写爽文"从"凭感觉"变成"按配方"，并且让配方随市场反馈持续进化。

- **产出目标**：8,000–12,000 汉字的女频短篇爽文，第一人称冷叙述，付费卡点落在全文 40%–50%
- **核心配方**：觉醒流（穿书/重生知死局）+ 身份落差（假千金/替身/炮灰女配）+ 全员误解 + 隐藏实力马甲 + 追妻火葬场（不回头）+ 付费卡点设计
- **进化机制**：每次投稿/改稿的结果都登记成案例，提炼成规则，合并回 skill——规则只进不出错，每一条都能指回来源案例

## 三、版本演进：每版都对应一次真实失败

| 版本 | 来源 | 解决了什么 |
| --- | --- | --- |
| v1 | 首篇范文拆解 | 九节骨架 + 卡点工程（铁证+暗刺+定格） |
| v2 | 一篇成稿的 45 处人工修改 | 文字品格：视角纪律、伏笔只埋不拆、称谓仪表盘、口语台词 |
| v3 | 洞洞猫退稿："男主女配中段下线，情绪断档" | 情绪续航六规则（双线在场/成就回流/火葬场螺旋等） |
| v4 | GPT 框架建议 + 白虎篇范文拆解 | 情绪层：情绪曲线任务卡、人物档案、弹幕装置、黑名单脚本化 |
| v5 | 二修被作者判"写的不好"：一板一眼跟写原剧情 | **范文对标复刻法**：拆机制→槽位映射→保留线锁定→声口取样→字数到节；附拉扯技法库十条、撞破误会型卡点、十节编号制骨架 |

教训浓缩成一句话：**范文管"怎么写"，用户点名的线管"保留什么"，原稿剧情只当素材库。**

## 四、产出硬指标（全部脚本可测）

| 指标 | 标准 |
| --- | --- |
| 总字数 | 8,000–12,000 纯汉字 |
| 卡点位置 | 全文 40%–50% |
| 段均长 | ≤26 字（单句成段） |
| 对话占比 | 25%–50% |
| 句长标准差 | ≥5（长短句交替） |
| 黑名单 | 零命中（情绪直说/升华收尾/辞藻腔） |
| 双线在场 | 男主/女配信号逐节核验，无连续两节断档 |
| 指定规格 | 用户给定节数/每节字数时，逐节实测 ±10% |

体检命令：

```bash
python3 xiaochengxu-houhvi-shuangwen/scripts/scan_shuangwen.py 稿.txt \
  --male '男主名1|男主名2' --female '女配名'
```

## 五、两套骨架

**九节骨架（默认）**：引子(2–3%) → 决裂宣言 → 三连斩断 → 低谷小爽 → 对峙卡点 → 卡点释放 → 真相揭晓 → 火葬场初段 → 公开处刑 → 封神收束。

**十节编号制变体**（用户指定"N 个编号各 1000 字"时）：引子 200–300 字 + 10 节等长（约 1000 字），打脸链前置半节，逐节功能表见 `structure.md §6`。

卡点五型：**铁证粉碎 / 身份曝光 / 危机降临 / 反转告白 / 撞破误会**——类型跟随主角的"隐藏底牌"走，完整手册见 `kadian.md`。

## 六、使用方式

**装进 Kimi**：把 `xiaochengxu-houhvi-shuangwen.skill` 上传安装，同名覆盖旧版即可。

**投稿反馈闭环**（配方进化的燃料）：

1. 投稿结果回来 → 按 `feedback.md §1` 模板登记案例（编辑原话一字不改）
2. 从案例提炼规则 → 合并进对应文件，飞书「改稿记录」状态改"已合并"
3. 过稿也记：编辑夸了什么 → 固化为加分项

**回归测试**（换模型/改规则后必跑）：用固定题材 T1（现言断亲）/ T2（古言重生替嫁）各跑开篇 500 字，与上次输出对比，质量不滑坡才算改对。
